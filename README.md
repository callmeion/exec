# แดชบอร์ดผู้บริหาร (ยอดขาย × ค่าแรง × พนักงาน)

เว็บ React (Vite) ที่ประมวลผลในเบราว์เซอร์ทั้งหมด ดึงข้อมูลจากไฟล์ Excel ที่ **เข้ารหัสแล้ว** และต้องใส่รหัสผ่านก่อนเห็นข้อมูล

## ขึ้น GitHub Pages (ครั้งแรก)
1. สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป (branch `main`)
2. เข้า **Settings → Pages → Build and deployment → Source = GitHub Actions**
3. รอ Actions ทำงาน (แท็บ Actions) → ได้ลิงก์ `https://<user>.github.io/<repo>/` ส่งให้หัวหน้าได้

## อัปเดตข้อมูล (ทุกสัปดาห์)
1. วางไฟล์ Excel ใหม่ในโฟลเดอร์ `data-source/` (เช่น Template_Sales_Payroll_Workforce_All_W17_W20.xlsx)
2. ดับเบิลคลิก `update-data.bat` (หรือรัน `npm run data` แล้ว commit/push เอง) → พิมพ์รหัสผ่านเมื่อถูกถาม
3. รอ 1–2 นาที เว็บจะอัปเดตเอง — ไฟล์ Excel ต้นฉบับ **ไม่ถูกอัปโหลดขึ้น GitHub** (มีแค่ `public/data/data.enc` ที่เข้ารหัสแล้ว)

> ไฟล์ `data.enc` ที่แถมมาเป็นข้อมูลตัวอย่าง (Mockup) เข้ารหัสด้วยรหัสผ่านที่แจ้งไว้ — ทับด้วยข้อมูลจริงเมื่อพร้อม

## ความปลอดภัย (อ่านก่อนใช้)
- ข้อมูลถูกเข้ารหัส AES-256-GCM คีย์มาจากรหัสผ่าน (PBKDF2 200,000 รอบ) ไม่มีรหัสผ่านอยู่ในโค้ด
- แต่ไฟล์ `data.enc` ดาวน์โหลดได้จากลิงก์เว็บ ผู้ที่รู้ลิงก์สามารถลองเดารหัสแบบออฟไลน์ได้ → **ใช้รหัสผ่านที่ยาวและเดายาก** (แนะนำ 12 ตัวอักษรขึ้นไป)
- อย่า commit ไฟล์ Excel ต้นฉบับ (`.gitignore` กันไว้ให้แล้ว) และเปลี่ยนรหัสผ่านเมื่อมีคนลาออก/ไม่ควรเห็นข้อมูลอีก (รันเข้ารหัสใหม่)

## พัฒนาในเครื่อง
`npm install` → `npm run dev` ; build: `npm run build`
